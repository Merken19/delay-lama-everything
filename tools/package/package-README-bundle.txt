Ready to play
-------------

This package brings a soundfont (soundfonts\), a cube map background
(backgrounds\) and songs to try (midi\). On the first start, midis2jam2
adds the soundfont to its list and selects it on the home tab, and shows the
cube map around the stage; the file picker opens in midi\. Anything you
change later (another soundfont, the default soundbank, another background
in Settings) stays as you set it. The cube map is copied to
%USERPROFILE%\.midis2jam2\backgrounds\, where midis2jam2 keeps its
backgrounds. If you move this folder, the soundfont moves with it.
